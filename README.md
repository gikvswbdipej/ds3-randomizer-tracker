## Overview

Dark Souls III Item Randomizer Tracker is a companion for DS3 randomizer runs, tracking which item locations have been checked, recording where key items have been found, managing hint credits, and visualizing an interactive map of all check locations — essential for multiworld randomizer races where item location awareness is critical.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Dark Souls III Item Randomizer Tracker** delivers the features you need in a clean, intuitive package.
